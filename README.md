# Reliability_FMs

## Repository status: under revision

The implementation originally released with the manuscript is currently
undergoing a complete audit.

Implementation and documentation issues were identified in the original
repository. A corrected implementation of the cross-scanner embedding
analysis, together with a downstream brain-age extension, is being prepared
and will be published here after validation.

The original repository state is preserved for transparency under the
[`legacy-original-code`](https://github.com/rafaloz/Reliability_FMs/tree/legacy-original-code)
tag, but it should not be considered the authoritative or validated
implementation.
